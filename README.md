# Code Samples – Karoliina Lundberg

A collection of code samples from my work as a full-stack developer. 
The code has been anonymized and simplified to remove proprietary details.

## Technologies
C#, ASP.NET Web API, Entity Framework, SQL Server

## Files

**ActivityController.cs**  
ASP.NET Web API controller for fetching activity timeline data. 
Demonstrates REST endpoint design, authorization, route configuration, 
and filtering data by type, tag, and date range.

**SqlReportsStatusRepository.cs**  
SQL repository for saving and retrieving report status data using 
Entity Framework. Demonstrates the repository pattern, upsert logic, 
and mapping between domain objects and database models.

**StockBalanceErrors.cs**  
Entity Framework database model for stock balance error tracking. 
Demonstrates composite primary key configuration and data annotations.
